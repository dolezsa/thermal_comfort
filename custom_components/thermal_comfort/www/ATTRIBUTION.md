# Attribution

`thermal_comfort_icons.js` is the `tc:` icon set of the
[Thermal Comfort icon pack](https://github.com/rautesamtr/thermal_comfort_icons)
by `rautesamtr`, bundled with this integration. The pack's author is fine with
the icons being part of this repository.

All icons are original or modified versions of icons from
[Material Design Icons](https://github.com/Templarian/MaterialDesign)
(Pictogrammers). The icons are modified and combined; the paths in the
JavaScript file are those of the modified icons. The list below gives
attribution to the creators of the original icons, as in the pack:

- fire: [@google](https://github.com/google)
- hand-extended: [@goyney](https://github.com/goyney)
- power-sleep: [@MrGrigri](https://github.com/MrGrigri)
- snowflake: [@google](https://github.com/google)
- thermometer: [@Templarian](https://github.com/Templarian)
- water: [@google](https://github.com/google)
- water-opacity: [@goyney](https://github.com/goyney)
- weather-sunny: [@Templarian](https://github.com/Templarian)

The loader code of the pack is based on
[hass-bha-icons](https://github.com/hulkhaugen/hass-bha-icons) by @hulkhaugen, as stated in the pack's README.

The integration itself uses three of the 15 icons: `dew-point`, `frost-point`
and `thermal-perception`.

code MIT).
